# Naeem Sayed — Portfolio V3

Responsive, static, zero-build professional portfolio for GitHub Pages.

## Files
- `index.html`, `styles.css`, `script.js` — website files
- `assets/` — project photographs
- `Doc_Resume.docx` — downloadable CV
- `favicon.svg` — browser tab icon

## Publish to existing GitHub Pages repository
Target repository: `NaeemSayed/NaeemSayed.github.io`, branch `main`, root folder.

**Recommended:** Go to GitHub → your repository → `Add file` → `Upload files`. Upload `index.html`, `styles.css`, `script.js`, `favicon.svg`, `README.md`, and `Doc_Resume.docx` from V3 root. Then **commit**. The existing `assets/` folder already contains all V2 images; no need to upload the same photos again unless you have changed them. If creating a fresh repository, also upload `assets/` into the `assets` directory.

The website uses relative paths, so existing URL `https://naeemsayed.github.io/` stays unchanged. Check `Actions` to confirm a successful Pages deployment. Refresh the website with Cmd+Shift+R / Ctrl+Shift+R.

## Edit a project
Project cards are in `index.html`. Detailed project descriptions and photo lists are defined in `script.js`, in the `projects` object. For any new image, upload it to `assets/` and use a relative path like `assets/example.jpg`.

## Important notes
- This portfolio is not an official website of the employers/clients referenced.
- Verify any project values or completion claims against your records before publishing.
- Review images to ensure they do not reveal confidential plans, personal information or unapproved site content.
- This site does not use a backend or collect visitor data.
